    线性空间

    线性空间，又称向量空间，是现代数学中的一个基本概念，是线性代数研究的主要对象。它推广了我们熟悉的二维和三维欧几里得空间的概念。

    定义

    一个线性空间 𝑉V 是一个集合，其上的元素称为向量。在这个集合上定义了两种运算：

    1. 向量加法：对于 𝑉V 中任意两个向量 ⃗𝑢u→ 和 ⃗𝑣v→，它们的和 ⃗𝑢 +⃗𝑣u→+v→ 仍然在 𝑉V 中。
    2. 标量乘法：对于 𝑉V 中任意向量 ⃗𝑣v→ 和一个标量（通常是实数 ℝR 或复数 ℂC）𝑐c，它们的积 𝑐⃗𝑣cv→ 仍然在 𝑉V 中。

    这两种运算必须满足以下八条公理（设 ⃗𝑢,⃗𝑣,⃗𝑤u→,v→,w→ 为 𝑉V 中任意向量，𝑐,𝑑c,d 为任意标量）：

    1. 加法交换律： ⃗𝑢 +⃗𝑣 =⃗𝑣 +⃗𝑢u→+v→=v→+u→
    2. 加法结合律： (⃗𝑢 +⃗𝑣) +⃗𝑤 =⃗𝑢 +(⃗𝑣 +⃗𝑤)(u→+v→)+w→=u→+(v→+w→)
    3. 存在零向量：存在一个零向量 ⃗0 ∈𝑉0→∈V，使得对于任意 ⃗𝑣 ∈𝑉v→∈V，都有 ⃗𝑣 +⃗0 =⃗𝑣v→+0→=v→。
    4. 存在负向量：对于任意 ⃗𝑣 ∈𝑉v→∈V，都存在一个负向量 −⃗𝑣 ∈𝑉−v→∈V，使得 ⃗𝑣 +( −⃗𝑣) =⃗0v→+(−v→)=0→。
    5. 标量乘法与标量加法的分配律： 𝑐(⃗𝑢 +⃗𝑣) =𝑐⃗𝑢 +𝑐⃗𝑣c(u→+v→)=cu→+cv→
    6. 标量乘法与向量加法的分配律： (𝑐 +𝑑)⃗𝑣 =𝑐⃗𝑣 +𝑑⃗𝑣(c+d)v→=cv→+dv→
    7. 标量乘法结合律： 𝑐(𝑑⃗𝑣) =(𝑐𝑑)⃗𝑣c(dv→)=(cd)v→
    8. 单位元：标量中的“1”满足 1⃗𝑣 =⃗𝑣1v→=v→。

    例子： - 所有 𝑛n 维实向量构成的集合 ℝ𝑛Rn 是一个线性空间。 - 所有次数不超过 𝑛n 的多项式构成的集合 𝑃𝑛(𝑥)Pn(x) 是一个线性空间。 - 在区间 [𝑎,𝑏][a,b] 上所有连续函数构成的集合 𝐶[𝑎,𝑏]C[a,b] 是一个线性空间。这在量子力学中尤其重要，波函数就存在于一个函数空间中。

    线性相关与线性无关

    在一组向量 {⃗𝑣1,⃗𝑣2,…,⃗𝑣𝑘}{v→1,v→2,…,v→k} 中，如果存在不全为零的标量 𝑐1,𝑐2,…,𝑐𝑘c1,c2,…,ck，使得：

    𝑐1⃗𝑣1+𝑐2⃗𝑣2+⋯+𝑐𝑘⃗𝑣𝑘=⃗0c1v→1+c2v→2+⋯+ckv→k=0→

    则称这组向量是线性相关的。这意味着其中至少有一个向量可以表示为其他向量的线性组合。

    反之，如果上述方程只在 𝑐1 =𝑐2 =⋯ =𝑐𝑘 =0c1=c2=⋯=ck=0 时成立，则称这组向量是线性无关的。

    例题： 判断三维向量 ⃗𝑎 =(1,0,0)a→=(1,0,0), ⃗𝑏 =(0,1,0)b→=(0,1,0), ⃗𝑐 =(2,3,0)c→=(2,3,0) 是否线性相关。

    解： 我们试图寻找不全为零的 𝑐1,𝑐2,𝑐3c1,c2,c3 使得 𝑐1⃗𝑎 +𝑐2⃗𝑏 +𝑐3⃗𝑐 =⃗0c1a→+c2b→+c3c→=0→。

    𝑐1(1,0,0)+𝑐2(0,1,0)+𝑐3(2,3,0)=(0,0,0)c1(1,0,0)+c2(0,1,0)+c3(2,3,0)=(0,0,0) (𝑐1+2𝑐3,𝑐2+3𝑐3,0)=(0,0,0)(c1+2c3,c2+3c3,0)=(0,0,0)

    这给出了方程组：

    {𝑐1+2𝑐3=0𝑐2+3𝑐3=0{c1+2c3=0c2+3c3=0

    我们可以取 𝑐3 =1c3=1，则 𝑐1 = −2,𝑐2 = −3c1=−2,c2=−3。因为存在不全为零的解（例如 𝑐1 = −2,𝑐2 = −3,𝑐3 =1c1=−2,c2=−3,c3=1），所以这组向量是线性相关的。事实上，⃗𝑐 =2⃗𝑎 +3⃗𝑏c→=2a→+3b→。

    基与维数

    基 (Basis)

    线性空间 𝑉V 的一个基是一组线性无关的向量 {⃗𝑒1,⃗𝑒2,…,⃗𝑒𝑛}{e→1,e→2,…,e→n}，满足 𝑉V 中的任何向量 ⃗𝑣v→ 都可以唯一地表示为这组基向量的线性组合：

    ⃗𝑣=𝑐1⃗𝑒1+𝑐2⃗𝑒2+⋯+𝑐𝑛⃗𝑒𝑛v→=c1e→1+c2e→2+⋯+cne→n

    标量 (𝑐1,𝑐2,…,𝑐𝑛)(c1,c2,…,cn) 称为向量 ⃗𝑣v→ 在这组基下的坐标。

    • 标准基：在 ℝ𝑛Rn 空间中，最常用的一组基是标准基，由单位向量构成。例如，在 ℝ3R3 中，标准基是 ˆ𝑖 =(1,0,0),ˆ𝑗 =(0,1,0),ˆ𝑘 =(0,0,1)i^=(1,0,0),j^=(0,1,0),k^=(0,0,1)。

    维数 (Dimension)

    一个线性空间 𝑉V 的维数是其任何一组基所包含的向量个数，记作 dim⁡(𝑉)dim⁡(V)。

    • 如果一个线性空间的维数是有限的，则称之为有限维线性空间。
    • 如果一个线性空间的基包含无限个向量，则称之为无限维线性空间。例如，所有连续函数构成的空间 𝐶[𝑎,𝑏]C[a,b] 是无限维的。量子力学中的希尔伯特空间就是无限维线性空间的一个重要例子。

    子空间

    如果 𝑊W 是线性空间 𝑉V 的一个非空子集，并且 𝑊W 本身对于 𝑉V 中定义的加法和标量乘法也构成一个线性空间，那么称 𝑊W 是 𝑉V 的一个线性子空间。

    要判断 𝑊W 是否为子空间，只需验证两点： 1. 对加法封闭：若 ⃗𝑢,⃗𝑣 ∈𝑊u→,v→∈W，则 ⃗𝑢 +⃗𝑣 ∈𝑊u→+v→∈W。 2. 对标量乘法封闭：若 ⃗𝑢 ∈𝑊u→∈W 且 𝑐c 是任意标量，则 𝑐⃗𝑢 ∈𝑊cu→∈W。

    例题： 判断集合 𝑊 ={(𝑥,𝑦,𝑧) ∈ℝ3|𝑥 +𝑦 +𝑧 =0}W={(x,y,z)∈R3|x+y+z=0} 是否为 ℝ3R3 的子空间。

    解： 1. 设 ⃗𝑢 =(𝑥1,𝑦1,𝑧1) ∈𝑊u→=(x1,y1,z1)∈W 和 ⃗𝑣 =(𝑥2,𝑦2,𝑧2) ∈𝑊v→=(x2,y2,z2)∈W。则 𝑥1 +𝑦1 +𝑧1 =0x1+y1+z1=0 且 𝑥2 +𝑦2 +𝑧2 =0x2+y2+z2=0。 它们的和为 ⃗𝑢 +⃗𝑣 =(𝑥1 +𝑥2,𝑦1 +𝑦2,𝑧1 +𝑧2)u→+v→=(x1+x2,y1+y2,z1+z2)。 其分量之和为 (𝑥1 +𝑥2) +(𝑦1 +𝑦2) +(𝑧1 +𝑧2) =(𝑥1 +𝑦1 +𝑧1) +(𝑥2 +𝑦2 +𝑧2) =0 +0 =0(x1+x2)+(y1+y2)+(z1+z2)=(x1+y1+z1)+(x2+y2+z2)=0+0=0。 所以 ⃗𝑢 +⃗𝑣 ∈𝑊u→+v→∈W。𝑊W 对加法封闭。

    1. 设 ⃗𝑢 =(𝑥1,𝑦1,𝑧1) ∈𝑊u→=(x1,y1,z1)∈W 且 𝑐c 为任意实数。则 𝑥1 +𝑦1 +𝑧1 =0x1+y1+z1=0。 标量积为 𝑐⃗𝑢 =(𝑐𝑥1,𝑐𝑦1,𝑐𝑧1)cu→=(cx1,cy1,cz1)。 其分量之和为 𝑐𝑥1 +𝑐𝑦1 +𝑐𝑧1 =𝑐(𝑥1 +𝑦1 +𝑧1) =𝑐(0) =0cx1+cy1+cz1=c(x1+y1+z1)=c(0)=0。 所以 𝑐⃗𝑢 ∈𝑊cu→∈W。𝑊W 对标量乘法封闭。

    因为 𝑊W 对加法和标量乘法都封闭，所以 𝑊W 是 ℝ3R3 的一个子空间。几何上，这个子空间是通过原点的一个平面。

    内积空间

    为了在线性空间中引入长度、距离和角度的概念，我们需要定义内积。一个内积空间是一个定义了内积运算的线性空间。

    内积（在实向量空间中通常就是点积）是一个函数，它接收两个向量，返回一个标量，记作 ⟨⃗𝑢,⃗𝑣⟩⟨u→,v→⟩。它必须满足以下性质（设 ⃗𝑢,⃗𝑣,⃗𝑤u→,v→,w→ 为向量，𝑐c 为标量）：

    1. 共轭对称性： ⟨⃗𝑢,⃗𝑣⟩ =――――⟨⃗𝑣,⃗𝑢⟩⟨u→,v→⟩=⟨v→,u→⟩― （对于实向量空间，即为对称性 ⟨⃗𝑢,⃗𝑣⟩ =⟨⃗𝑣,⃗𝑢⟩⟨u→,v→⟩=⟨v→,u→⟩）
    2. 对第一变元的线性： ⟨𝑐⃗𝑢 +⃗𝑣,⃗𝑤⟩ =𝑐⟨⃗𝑢,⃗𝑤⟩ +⟨⃗𝑣,⃗𝑤⟩⟨cu→+v→,w→⟩=c⟨u→,w→⟩+⟨v→,w→⟩
    3. 正定性： ⟨⃗𝑣,⃗𝑣⟩ ≥0⟨v→,v→⟩≥0，且 ⟨⃗𝑣,⃗𝑣⟩ =0⟨v→,v→⟩=0 当且仅当 ⃗𝑣 =⃗0v→=0→。

    在内积空间中，我们可以定义： - 向量的范数（长度）： ‖⃗𝑣‖ =√⟨⃗𝑣,⃗𝑣⟩‖v→‖=⟨v→,v→⟩ - 向量间的夹角 𝜃θ： cos⁡𝜃 =⟨⃗𝑢,⃗𝑣⟩‖⃗𝑢‖‖⃗𝑣‖cos⁡θ=⟨u→,v→⟩‖u→‖‖v→‖ - 正交：如果 ⟨⃗𝑢,⃗𝑣⟩ =0⟨u→,v→⟩=0，则称向量 ⃗𝑢u→ 和 ⃗𝑣v→ 是正交的。

    例子： - 欧几里得空间 ℝ𝑛Rn 加上点积运算，构成一个内积空间。 - 对于复变函数空间 𝐶[𝑎,𝑏]C[a,b]，可以定义内积为 ⟨𝑓,𝑔⟩ =∫𝑏𝑎𝑓(𝑥)―――𝑔(𝑥)𝑑𝑥⟨f,g⟩=∫abf(x)g(x)―dx。这在量子力学中用于计算波函数的归一化和跃迁概率。
